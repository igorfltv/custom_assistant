# Проверка корпуса ТК ЕАЭС — 15 ноября 2026

Корпус содержит все 465 статей из [оглавления Альта-Софт](https://www.alta.ru/codex-2018/contents/).
В нём 1 685 823 символа текста. Проверена полнота сохранения текста и его доступность
поиску; это не утверждение применимости всех редакций на дату декларации.

## Происхождение и качество

- С Альты последовательно получены страницы 1–230. Запрос статьи 231 вернул HTTP 403;
  дальнейшие запросы загрузчика остановлены. Ограничения сайта не обходились.
- В итоговом корпусе 229 статей представлены публикациями Альты, 236 —
  [официальным PDF ЕЭК](https://eec.eaeunion.org/upload/iblock/93c/TK-EAES.pdf).
  Для PDF сохранены номера страниц и отдельные идентификаторы статей.
- Статья 131 взята из PDF: в опубликованный текст страницы Альты попал фрагмент
  повреждённой HTML-разметки. Оригинальные байты обеих публикаций сохранены.
- Для всех HTML-статей извлечённый текст посимвольно сопоставлен с контейнером
  публикации без учёта пробелов. Меню, голосования и комментарии исключены.
- PDF содержит 465 последовательных заголовков. Результаты PDFium и независимого
  извлечения Poppler совпали для всех 465 статей после нормализации пробелов и
  переносных дефисов. Границы статей, глав и приложений проверены; номера страниц
  исключены из текста. Визуально проверено отображение переносов в PDF.
- Из 230 доступных HTML-статей 223 совпали с PDF после нормализации пробелов,
  пунктуации и регистра. Различия в 55, 69, 73, 74, 77 относятся к символу `N`,
  в 109 — к одному союзу; 131 содержит повреждённую разметку. Тексты не смешивались.

### Известные ограничения редакций

Статья 321 и на Альте, и в исходном PDF не учитывает изменения пункта 2,
внесённые [Протоколом от 29.05.2019](https://docs.eaeunion.org/documents/236/4435/)
и вступившие в силу 23.03.2021. В метаданных статьи сохранены `publication_warning`
и `known_amendments`; они передаются при поиске и чтении снимка и в контекст модели.
Инструкция проверки запрещает применять такой исходный текст как действующее
требование. Текст источника не переписан от имени издателя.

Все новые снимки имеют `pending_review`, без автоматически утверждённых периодов
действия. Полное покрытие 465 статей не равно полной нормативной базе или проверке
всех изменений законодательства. Резервный PDF загружен как проверенный снимок;
фоновое обновление страниц Альты по-прежнему соблюдает robots.txt и паузы сервера.

## Изменения в агенте

- Обход принимает статьи раздела IX вида `/R9/ST444/`, разделы и главы.
- Отдельный извлекатель проверяет контейнер, номер и заголовок статьи.
- Новая версия извлечения отделена от старых снимков; старые цитаты и архивы
  не перезаписываются. Статьи одного PDF имеют разные текстовые файлы.
- Точный запрос номера статьи возвращает статью Кодекса. Для текстовых запросов
  при ранжировании учитывается совпадение заголовка с содержательными словами запроса.
- При проверке ДТ агент обязательно извлекает статьи 106 и 108 о составе сведений
  и подтверждающих документах. Цитаты проверяются по реально переданным фрагментам.
- `knowledge.status(...).codex` показывает ожидаемое число, число индексированных
  статей, пропуски и `text_complete`. Общий `coverage_complete` не объявляется true.

## Результаты проверок

- 465/465: номер, заголовок, контрольные суммы, сохранённый снимок, восстановление
  полного текста из FTS-фрагментов с перекрытием, поиск по точному номеру.
- 9/9 текстовых запросов: нужная статья в первых трёх результатах. Проверены сведения
  ДТ (106), документы (108), срок подачи (110), стоимость сделки (39), права декларанта
  (84), внутреннее потребление (135), переходные положения УЭО (465), классификация
  (20), происхождение (28).
- 2/2 сценария с реальной `deepseek-flash` через `pipeline.review_fields`:
  недостающие документы → цитирование статьи 108; недостающие сведения → статьи 106.
  Переданные модели фрагменты, ответы и проверенные выводы сохранены. В ходе проверок
  защита отклонила рекомендацию для неизвестного товара и неподтверждённую цитату.
- Тесты рабочей копии: agent — 100 passed, backend — 32 passed. У backend остаётся
  предупреждение зависимости Starlette/httpx. Для изолированной поставки отдельно
  проверены 37 тестов поиска, цитирования, pipeline и контекста оператора.

Машинные материалы находятся в `.local/codex-audit/`: `coverage.json`,
`local-coverage.json`, `semantic-search.json`, `live-review-report.json`,
полные ответы модели в `missing_documents.json` и `missing_particulars.json`,
оригинальные источники и контрольные суммы в `corpus-bundle.tar.gz`.

## Воспроизведение проверки корпуса

```bash
backend/.venv/bin/python -m forma_declaration_agent.codex_corpus \
  --bundle .local/codex-audit \
  --data-dir .local/declaration-eval \
  --report .local/codex-audit/local-coverage.json --audit-only
```

Без `--audit-only` команда предварительно проверяет весь пакет и затем импортирует
его под блокировкой краулера, сохраняя существующую базу других источников.
