# Заполнение российской ДТ. Проверка от 22 ноября 2026 года

Проверены правила для обычной декларации на товары, подаваемой в РФ при ввозе и вывозе. Статья 95 Федерального закона № 289-ФЗ отсылает к главе 17 ТК ЕАЭС. Состав сведений определяет статья 106 Кодекса, подтверждающие документы — статья 108. По пункту 5 статьи 105 порядок заполнения устанавливает Комиссия. Поэтому для конкретных граф применялось Решение КТС № 257, а для классификаторов — Решение № 378. [Статья 95 закона № 289-ФЗ](https://www.consultant.ru/document/cons_doc_LAW_304093/08080c8cf761cbc7245a812a399693d9b3ceed40/) · [ТК ЕАЭС](https://eec.eaeunion.org/upload/iblock/93c/TK-EAES.pdf) · [Официальная публикация Решения № 257](https://docs.eaeunion.org/documents/214/946/) · [Текст Порядка по разделам](https://www.consultant.ru/document/cons_doc_LAW_101257/)

## Происхождение по графам 16 и 34

Графа 34а относится к конкретному товару. Графа 16 обобщает сведения обо всех товарах. Для одного происхождения указывается краткое наименование. Для разных стран, в том числе сочетания известного и явно неизвестного происхождения, указывается «РАЗНЫЕ». Если происхождение всех товаров неизвестно, указывается «НЕИЗВЕСТНО». Отсутствие страны в извлечённых данных оставляет вопрос открытым. При ввозе обозначение ЕС требует проверки документов о происхождении и мер, зависящих от конкретной страны. При вывозе порядок предусматривает код конкретной страны либо неизвестное происхождение. [Графа 16 при ввозе](https://www.consultant.ru/document/cons_doc_LAW_101257/c51a6db1e28a71847d33ddfdfd9db876e6203709/) · [Графа 34 при ввозе](https://www.consultant.ru/document/cons_doc_LAW_101257/c6eb9cb9b9b9d4972daffaaedfe816cc286d18a1/) · [Графа 16 при вывозе](https://www.consultant.ru/document/cons_doc_LAW_101257/59cadbacf7a5ae65a4120fc05eabdfc20e961ec2/) · [Графа 34 при вывозе](https://www.consultant.ru/document/cons_doc_LAW_101257/146feb30f66c6222d3a7378f9e332bbdbccbc7d7/)

Forma рассчитывает графу 16 по заполненным и согласованным графам 34. Для названий используется таблица из 249 действующих строк приложения 22. Для автоматического применения общего правила ввоза и вывоза нижняя граница проверки — 1 января 2021 года, когда вступило в силу Решение Коллегии ЕЭК № 126. Без даты подбора редакции результат помечается для проверки. Для более ранней даты нужен исторический разбор. Применимость графы при специальных операциях, в частности при перемещении выручки от торговли на транспорте, проверяется отдельно. [Карточка Решения № 126 и дата вступления в силу](https://docs.eaeunion.org/documents/335/5252/) · [Классификатор стран мира](https://www.consultant.ru/document/cons_doc_LAW_105110/c992fcdc75e42dfec5fb49115425f217bed8eb8e/)

Когда в распознанном тексте маркировки есть страна изготовления и точный идентификатор модели, связанный с единственной позицией, Forma сопоставляет их со страной в документах этой позиции. При расхождении в вопросе сохраняются обе версии, изображение или страница и буквальная цитата. Специалист может проверить, относится ли маркировка к самому товару. Общий вывод о стране при открытом конфликте не рассчитывается.

## Процедура по графам 1 и 37

Первый подраздел графы 37 содержит два двузначных элемента для заявляемой и предшествующей процедур. При определении второго элемента учитываются исключение для таможенного транзита и правила для товаров, полученных в результате переработки. Второй подраздел содержит трёхзначный код особенности перемещения по приложению 2 к Решению № 378. [Пункт 15, подпункт 35 Порядка](https://www.consultant.ru/document/cons_doc_LAW_101257/dde8e2515e408daa2430b96d27b4e24bae0be844/) · [Отсылка для вывоза в пункте 17](https://www.consultant.ru/document/cons_doc_LAW_101257/69aae946dd7659694f15ebd602ab28cdcf5d7bc9/) · [Решение № 378](https://docs.eaeunion.org/upload/iblock/2ab/9yz4w2swoprc5gn7xlwkabutd2yqysmf/cuc_21092010_378_doc.html)

Четыре цифры сохраняются как частичный ввод. Для XML требуется полный код. При заполненной графе 1 проверяется совпадение заявляемой процедуры. Право применять выбранный код особенности перемещения к товару требует сведений о поставке и проверки классификатора на дату ДТ.

## Стоимость по графам 12, 22, 42 и 45

Для российской ДТ графа 22 содержит валюту цены договора. При нескольких валютах используется преобладающая валюта цены, при отсутствии договора используются коммерческие документы. Цена в графе 42 выражается в валюте графы 22. Цены и таможенные стоимости округляются до сотых по каждому товару ДТ после группировки исходных строк. Итог графы 22 сверяется с суммой граф 42, а общая таможенная стоимость в графе 12 — с суммой граф 45. Если основание для графы 45 установлено лишь у части товаров, для автоматического итога требуется отдельно различать правомерное незаполнение и недостающие данные. [Графа 22](https://www.consultant.ru/document/cons_doc_LAW_101257/5451d4d1d9b0733fc7034a44ec7e8cf0388a9d4f/) · [Графа 42](https://www.consultant.ru/document/cons_doc_LAW_101257/d913e0ac20d63105544dc9672baa029b6f9ef55c/) · [Графа 12](https://www.consultant.ru/document/cons_doc_LAW_101257/3c0fd3c109cf927e314d5345c00555276d50c5a5/) · [Графа 45](https://www.consultant.ru/document/cons_doc_LAW_101257/0652c0ee0b44311efa37fcf394b4c8b6edea46a8/)

При расхождении итог остаётся в черновике с пояснением и пропускается в XML. Специалист видит, какие расходы или скидки нужно проверить. Смена валюты в шапке не пересчитывает цену, извлечённую из инвойса в другой валюте.

Контрольный пример использует две исходные строки по 10,005. Если это два отдельных товара ДТ, их цены округляются до 10,01 каждая, итог составляет 20,02. Если обе строки правомерно объединены в один товар ДТ, его цена составляет 20,01.

## Проверка на сохранённых комплектах

К сохранённым полям и текстам пяти комплектов повторно применили проверку маркировки, расчёт граф и экспорт. Эталонные декларации использовались только для сравнения результата. У четырёх комплектов отсутствовала дата подбора редакции. Для них дополнительно проверен сценарий с датой 22 ноября 2026 года. Это дата эксперимента.

В одном комплекте оба реквизита графы 16 совпали с эталонным AltaGTD при заданной дате. В другом точное совпадение модели связало документальное расхождение с конкретным товаром. Графа 34 этого товара и графа 16 остались открытыми. Проверка стоимостей обнаружила один несогласованный итог графы 22. В трёх остальных комплектах данных для общего вывода по графе 16 оказалось недостаточно.

Во всех пяти сохранённых черновиках отсутствовал экспортируемый код графы 37. Её частичный ввод, дополнение и расхождение с графой 1 проверены отдельными тестами через API до выгрузки XML. Эталоны AltaGTD подтверждают представление полного кода одной строкой и сочетание «РАЗНЫЕ» с техническим кодом 00. Для «НЕИЗВЕСТНО» адаптер выгружает текст, поскольку отдельный технический код для этого случая по примерам не установлен. Полный новый модельный прогон, импорт в Альта-ГТД, подбор ставок, расчёт платежей и проверка всех специальных процедур в эту проверку не входили.
