# Форма — рабочая спецификация

Подтверждено 2026-11-12. Одна компания, сотрудники; 150–300 ДТ/месяц.
Ввоз в РФ, выпуск для внутреннего потребления, целевой охват всей ТН ВЭД.
Результат — только файл XML декларации. Пользователь вручную загружает его в Альту.
Продукт не подключается к Альте и не отправляет декларации в ФТС.
Примеры комплектов и эталонные XML пользователь предоставит позже.

## Компоненты

- custom_assistant — оркестрация, локальный и удалённый деплой, общие UI-примитивы и документация.
- custom_assistant-backend — Python API, очередь, обработка документов, провайдеры, правила.
- custom_assistant-landing — публичный сайт.
- custom_assistant-workspace — кабинет специалиста.
- custom_assistant-admin — администрирование.

Приложения — отдельные Git-репозитории и сборки. Корневой репозиторий фиксирует
их коммиты git submodules. Общий npm workspace собирает frontend-приложения
с одним пакетом UI; бизнес-логика кабинета и админки не смешивается.

## Интерфейсы

Референс: https://ui.gradientdeck.com/styles/family — тёплый светлый фон,
спокойная типографика, чёрные кнопки, акценты и мягкие карточки.
Сотрудник: документы → контекст поставки → анализ → вопросы → правки → XML.
Контекст: что за товары, назначение/состав/особенности, участники, откуда/куда,
условия поставки, что подтверждает каждый документ, противоречия и неизвестное.
Каждый вывод подкрепляется источником, предположения маркируются.

## Модели

Внешние провайдеры разрешены. OpenAI, Anthropic, Gemini, DeepSeek,
OpenRouter, Mistral, совместимый API. Отдельный выбор OCR и анализа.
Модели, OCR-движки, фактические вызовы и расходы видны в UI.
Изменение профиля не меняет уже начавшийся запуск. Ключи зашифрованы.

## Этапы и критерии

1. Репозитории, воспроизводимый запуск, auth/роли, CI, инфраструктура.
2. Лендинг, кабинет и админка; загрузка, документы и источники, контекст поставки.
3. Реальная очередь OCR/LLM, профиль провайдеров, поля, противоречия и уточнения.
4. Версионированные нормы, справочники и движок применимости по товарам.
5. Подтверждённая XSD, отображение реквизитов и XML-экспорт.
6. Эталонные комплекты, проверка декларантом, ручная проверка совместимости XML.

Прототип не объявляет документы готовыми, пока нет подтверждённых правил и XML-схемы.
Каталог 54 граф — интерфейсный каталог, не полная модель электронного документа.
Текущие проверки — базовые, их недостаточно для правового заключения о полноте ДТ.

## Размещение

VM 89.232.170.118, SSH пользователь filatov. Секреты вне репозитория.
Домена нет: порт приложения привязан к loopback, доступ через SSH-туннель.
Docker Compose: proxy, backend, worker, postgres, redis, knowledge sync.
Один локальный скрипт, отдельный скрипт удалённого развёртывания.

## Ещё неизвестно

Пиковое число позиций и документов, целевой XML-формат/версия XSD,
учётные данные LLM, эталонные комплекты и правила специальных категорий.
